## Zepp / Amazfit mit Token

Wer sich bei Zepp mit Google, Apple oder Mi anmeldet, hat kein Passwort und konnte die
Zepp-Cloud bisher nicht nutzen. Jetzt geht es mit dem Zugangs-Token („apptoken“):
Unter Touren importieren → Zepp / Amazfit → „Mit Token“ steht die Anleitung, dazu ein
Hilfstext, der das Token im Browser ausliest und kopiert. Das Token wird geprüft, bevor
es gespeichert wird; optional lässt sich der Server angeben. Danach gibt es „Zugang
testen“ und „Abmelden“. Abgelaufene Token werden mit einem klaren Hinweis gemeldet.

Die Anmeldung mit E-Mail und Passwort bleibt als zweite Möglichkeit erhalten.
