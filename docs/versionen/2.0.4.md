# 2.0.4 – Namen von Komoot

- **Der Komoot-Import übernimmt jetzt die Tournamen** – auch für Touren, die schon aus Zepp, aus einer Datei oder aus der
  eigenen Aufzeichnung in der App sind. Bisher wurden solche Touren nur als „schon vorhanden“ gezählt und behielten den
  selbst erzeugten Namen („Wandern am Mittag · 19.11.26“).
- **Regel:** Ersetzt wird nur ein selbst erzeugter Name – oder der Name, der zuletzt von Komoot kam. Benennst du eine Tour
  in Komoot um, zieht der Name beim nächsten Import nach. Einen Namen, den du in der App von Hand vergeben hast, fasst der
  Import nicht an.
- **Zuordnung:** gleiche Startzeit (± 5 Minuten) und ähnliche Länge (± 10 %). Die Zuordnung wird an der Tour gemerkt;
  die Spur wird dafür nicht mehr von Komoot geladen. Der Import ist dadurch bei vielen vorhandenen Touren deutlich schneller.
- Nach dem Import steht dort z. B. „Name bei 12 Touren von Komoot übernommen“.

So geht es: Mehr → Touren importieren → Komoot → importieren.

Nicht geändert: Java-Teil, Aufzeichnung, Sicherungsformat (neue Felder `komootId`, `nameKomoot` an der Tour gehen in die Sicherung mit).
