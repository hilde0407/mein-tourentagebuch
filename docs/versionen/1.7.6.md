## Fotos vom Rechner im WLAN empfangen

Fotos ＋ → **Vom Rechner im WLAN** (auch beim Hinzufügen zu einer Tour): Das Handy zeigt eine Adresse wie `http://192.168.0.23:8765/k3x9a/`. Öffne sie im Browser deines Macs oder PCs (im selben WLAN) und ziehe Fotos auf die Seite oder wähle sie aus. Sie werden sofort auf dem Handy importiert und den Touren nach Aufnahmezeit zugeordnet.

- Der Empfang läuft nur, solange das Fenster in der App offen ist.
- Die Adresse enthält ein zufälliges Kennwort, das bei jedem Start neu entsteht.
- Die Übertragung ist nicht verschlüsselt – nur im eigenen WLAN nutzen.
- Eine Datei darf bis 120 MB groß sein. Auf dem Rechner muss nichts installiert werden.
