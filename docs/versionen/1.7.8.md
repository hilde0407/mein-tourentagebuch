# 1.7.8

- Reisen werden jetzt genau wie in „Meine Touren“ erkannt: Das Heimatgebiet wird automatisch aus deinen Touren bestimmt (oder dein eingetragener Heimatort), Touren über 60 km davon entfernt bilden eine Reise, eine Tour zu Hause beendet sie. Pausen bis 7 Tage im gleichen Gebiet (150 km) gehören dazu.
- Mehrtagestouren werden wie in „Meine Touren“ an den Namen erkannt („… Tag 3“, „… Etappe 2“).
- Einstellbar bleibt die Mindestzahl Tage einer Reise (Standard 4).
