# 2.20.2 – Statistik-Gruppen mit kurzem Namen

Anlass: Seit 2.20.1 zeigen die Anzeigen nur den Gruppennamen. Gruppen ohne Namen bekamen aber einen Ersatznamen aus den Sportarten („Wandern + Berg + Schneeschuh“, auf 30 Zeichen gekürzt) – das sah wieder wie eine Aufzählung aus („Zusammengefasst sieht das aber nicht aus“).

**Ehrlich vorweg:** Keine gespeicherten Daten werden verändert. Geprüft mit den Rechentests (Node), dem Begriffe-Test und im Browser-Test; nicht auf einem Handy.

## Neu
- **Kurzer Name beim Anlegen:** Der Name ist Pflichtfeld. Beim Ankreuzen der ersten Sportart wird er vorbelegt: „<erste Sportart> (gesamt)“, z. B. „Wandern (gesamt)“ (solange der Name leer ist oder noch der Vorschlag). Der Vorschlag „Wandern + Bergsteigen + Schneeschuh“ heißt jetzt „Wandern (gesamt)“ (vorher „Bergtouren“); „Rad“ und „Ski“ bleiben. „(gesamt)“ erfüllt die Regel „Name nicht wie eine Sportart“.
- **Alte Aufzählungsnamen:** Heißt eine bestehende Gruppe nur wie die Aufzählung ihrer Sportarten (der frühere automatische Ersatzname, auch gekürzt), steht im Editor „Name ist nur eine Aufzählung – kürzer benennen?“ mit dem Knopf „Vorschlag übernehmen: Wandern (gesamt)“. Ein Tipp speichert sofort; nichts wird von selbst umbenannt.
- `StatGruppen.sauber()`: Der Fallback für Gruppen ohne Namen (nur beschädigte oder importierte Daten, Sicherung, MT-Abgleich) ist jetzt ebenfalls kurz („<Sportart> (gesamt)“). Neu: `kurzName()`, `nurAufzaehlung()`, `vorschlagName()`.

## Tests
- `tests/test_calc.js`, `tests/test_begriffe.js`: Namensvorschlag, Erkennung „Name ist nur Aufzählung“, kurzer Fallback.
- `tests/test_web.py`: Vorbelegung beim Anlegen, Hinweis und Übernehmen-Knopf; bestehende Erwartungen angepasst.
