# 2.5.1 – PDF per WhatsApp teilen

Fehler behoben: Beim Teilen eines PDFs konnte man in WhatsApp zwar den Empfänger wählen, das PDF kam aber nicht an (E-Mail funktionierte).
Ursache: Der interne Dateianbieter meldete PDFs als „Bild“ und lieferte keinen Dateinamen und keine Größe. WhatsApp braucht beides.
Jetzt: Typ `application/pdf`, Name und Größe werden mitgeliefert, das Teilen enthält zusätzlich eine Dateiangabe (ClipData).
Betrifft nur Java (PhotoProvider, MainActivity); keine Änderung an den Daten.
