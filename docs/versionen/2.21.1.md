# 2.21.1 – Update-Prüfung funktioniert auf dem Handy

**Fehler in 2.21.0:** „Jetzt prüfen“ meldete auf dem Handy „Prüfung nicht möglich: keine Verbindung“, obwohl das Netz da war.

**Ursache:** Die Anfrage an GitHub trug im Kopf „User-Agent“ den Text „… (Update-Prüfung)“ mit einem Umlaut. Die Netzwerkbibliothek der App (OkHttp) lässt in Kopfzeilen nur ASCII-Zeichen zu und brach die Anfrage ab, bevor sie das Netz erreichte. Im Browser-Test fiel das nicht auf, weil dort keine OkHttp-Brücke läuft.

## Behoben
- Kopfzeile ist jetzt reines ASCII („MeinTourentagebuch/<Version> (update-check)“).
- Der Test prüft, dass die Kopfzeilen der Update-Prüfung nur ASCII enthalten.

**Ehrlich vorweg:** Auf einem Handy habe ich es nicht nachgeprüft; die Ursache ergibt sich aus dem Code (OkHttp) und der Meldung „keine Verbindung“, die genau bei einem Ausnahmefehler der Brücke erscheint.
